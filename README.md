## Sobre mim

Sou desenvolvedor backend em formação, com foco em **Python** e na construção
de **APIs REST**. Estudo Análise e Desenvolvimento de Sistemas e aprendo na
prática: cada projeto deste perfil tem modelagem de dados, autenticação e
testes automatizados.

Meu interesse por tecnologia começou no ensino médio, em uma escola integrada,
e hoje é a carreira que escolhi construir.

**Busco minha primeira oportunidade como Desenvolvedor Backend Python Júnior.**
